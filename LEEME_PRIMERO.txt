DAEDALUS V11.3 — CORRECCIÓN DEL ERROR TAINTED CANVAS

El mensaje de error confirmó que el exportador anterior contaminaba el canvas
al convertir todo el HTML mediante foreignObject.

Esta versión:
- rasteriza la plantilla SVG local;
- dibuja el texto directamente sobre canvas;
- evita el error “Tainted canvases may not be exported”.

INSTALACIÓN CON GITHUB DESKTOP

1. Abre:
   Documentos/Daedalus/herramientas-contenido

2. Arrastra dentro el contenido de esta actualización.
   Conserva la carpeta js y el archivo dentro de exporters.

3. Reemplaza:
   - js/exporters/exporter.js
   - service-worker.js
   - version.json

4. En GitHub Desktop escribe:
   Daedalus V11.3 - corregir tainted canvas

5. Commit to main.
6. Push origin.
7. Espera GitHub Pages.

   comunicado.html?v=1130
