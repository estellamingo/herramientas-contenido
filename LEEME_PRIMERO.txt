DAEDALUS V11.2 — ACTUALIZACIÓN LOCAL CON GITHUB DESKTOP

1. Abre en Finder la carpeta local:
   Documentos/Daedalus/herramientas-contenido

2. Abre esta carpeta ACTUALIZACION_LOCAL_V11_2.

3. Arrastra su contenido sobre la carpeta herramientas-contenido.
   macOS preguntará si deseas reemplazar los archivos existentes.
   Elige REEMPLAZAR.

IMPORTANTE:
- No arrastres la carpeta ACTUALIZACION_LOCAL_V11_2 completa.
- Arrastra los archivos y la carpeta js que están dentro.
- La estructura debe quedar así:

herramientas-contenido/
├── comunicado.html
├── service-worker.js
├── version.json
└── js/
    ├── app.js
    └── exporters/
        └── exporter.js

4. Vuelve a GitHub Desktop.
5. Deben aparecer 5 archivos modificados.
6. En Summary escribe:
   Daedalus V11.2 - corregir exportación de comunicados
7. Pulsa Commit to main.
8. Pulsa Push origin.
9. Espera el despliegue de GitHub Pages.
10. Prueba:
    https://estellamingo.github.io/herramientas-contenido/comunicado.html?v=1120
