# Daedalus V8 — PWA

Esta versión añade instalación como aplicación web progresiva.

## Publicación en GitHub Pages
Sube el contenido de esta carpeta a la raíz del repositorio y espera a que Pages vuelva a desplegar.

## Instalación en iPhone
1. Abre la URL en Safari.
2. Pulsa Compartir.
3. Selecciona “Añadir a pantalla de inicio”.
4. Confirma el nombre Daedalus.

La V8 sigue usando internet para algunas dependencias externas. El modo completamente sin conexión se abordará en una versión posterior.
